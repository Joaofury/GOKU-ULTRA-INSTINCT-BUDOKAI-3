COMO INSTALAR/ HOW TO INSTALL
1. Feche o jogo.
2. Extraia a pasta "mods" do zip DIRETO na pasta do jogo (onde fica o dbz3.exe) e
   aceite juntar/substituir. Tem que ficar assim:
       <pasta do jogo>\mods\gokuui_sdbh\personaje.toml
       <pasta do jogo>\mods\_roster\roster.toml
3. Abra o jogo pelo launcher. O Goku UI aparece numa casa nova da roda do select,
   ja com os sons do Heroes. Nao precisa rodar nada.
